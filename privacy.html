Privacy Policy

Last updated: November 2026

This Privacy Policy describes how the Personal Google Drive Backup tool (“the App”) handles data.

What data is accessed

The App accesses Google Drive files and related metadata only when you explicitly authorize it. Access is used exclusively to upload, download, list, and manage backup files in your own Google Drive account.

How the data is used

  • To perform the backup and restore operations you request.
  • To store authentication tokens locally on the device or server running the App so the backup can run unattended.

Data sharing and storage

No Google user data is shared with any third party. Files and tokens remain under your control. The App does not transmit your files or credentials to any external service other than Google Drive itself.

Limited Use

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

This is a personal tool. For questions, contact the owner of this GitHub repository.
